# CodeCanyon Item Listing — SiteForge AI

## Suggested title

SiteForge AI — Local Windows AI Website Builder with Visual Editing and One-Click Deploy

## Short description

Create real HTML/CSS/JavaScript websites from natural-language prompts, edit any element directly in Live Preview with AI, validate changes, export ZIP files, and deploy safely to FTP, FTPS, SFTP, cPanel or DirectAdmin from a local Windows desktop application.

## Feature description

SiteForge AI is a local-first Windows website creation studio for freelancers, agencies and developers. It combines AI website generation, real file editing, click-to-select visual editing, previews, SEO checks, project validation, backups, deployment diffs and hosting deployment in one desktop workflow.

The application supports BYOK configuration for OpenAI, Gemini, Claude and OpenRouter. Generated websites contain real HTML, CSS, JavaScript and SEO files. Visual edits create a local backup, show a proposed change, write the approved change to the project files and refresh the preview.

## Included workflows

Create from a brief; import a folder or ZIP; edit in the visual preview; edit real source files; run AI Repair; analyze SEO; validate the project; export ZIP; configure hosting; review a deployment diff; create a backup; deploy; verify the live URL; inspect history; and restore a reviewed version.

## Requirements

Windows 10 or Windows 11 x64. No Python or Node.js is required after installing the compiled release. An internet connection and an account with a supported AI provider are required only for remote AI operations. Hosting credentials are required only for deployment.
