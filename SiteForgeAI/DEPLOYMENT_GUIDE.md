# Deployment Guide

اختر المشروع ثم استخدم Validate Project. يجب إصلاح Critical قبل النشر. يعرض التطبيق فروقات الملفات، ثم ينشئ Backup محليًا ويطلب تأكيدًا. لا يُحذف أي ملف بعيد تلقائيًا دون تأكيد صريح.

يدعم المسار الحالي FTP وFTPS وSFTP، كما يحتوي المشروع على adapters لـ cPanel وDirectAdmin عند توفر بيانات الوصول والـAPI المناسب. اختبر الاتصال على مجلد تجريبي أولًا، ثم استخدم المسار البعيد الصحيح مثل `/public_html`.

كل عملية نجاح أو فشل تُسجل محليًا مع البروتوكول والمسار ونسخة النسخ الاحتياطي. استخدم History لاستعادة إصدار محلي سابق قبل إعادة النشر.
