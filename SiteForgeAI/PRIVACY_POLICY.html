SiteForge AI Privacy Policy

Effective date: August 13, 2026

Local-first storage

SiteForge AI stores project files, local database records, version backups, settings and encrypted credentials on the user's device. The application does not require a SiteForge cloud account or a SiteForge backend.

AI providers

When the user starts an AI operation, the application may send the user's prompt and the minimum selected project context to the configured provider: OpenAI, Gemini, Claude or OpenRouter. The provider processes that request under its own privacy policy and terms. Users should remove sensitive information before submitting it.

Hosting providers

When the user confirms deployment, files and connection metadata are sent to the selected hosting endpoint using the configured FTP, FTPS, SFTP, cPanel or DirectAdmin protocol. SiteForge AI does not control the hosting provider's retention or security practices.

Credentials

AI keys and hosting credentials are never included in generated websites or exported ZIP files. They are stored through the local secure store. Users remain responsible for protecting their Windows account and device.

Telemetry

SiteForge AI does not intentionally collect analytics or telemetry. Crash reports are not automatically uploaded by the application.

Deletion

Users may delete local projects, versions and settings through Windows file management. Remote files are not deleted automatically by the application.

Contact

For support, provide only non-sensitive diagnostic information. Never send API keys, passwords or private project files.
