# SiteForge AI Support Policy

SiteForge AI 1.0.0 includes support for documented installation, application workflows and reproducible defects in the submitted build. Support requests should include the application version, Windows version, exact error text, selected provider or deployment protocol, and clear reproduction steps.

Support does not include third-party provider billing, provider-side API failures, hosting configuration, DNS, SSL certificates, server administration, custom website implementation, or changes to the buyer's private project without a reproducible defect report.

Never send API keys, passwords, private hosting credentials or confidential project files in a support request. Redact logs and screenshots before sharing them.
