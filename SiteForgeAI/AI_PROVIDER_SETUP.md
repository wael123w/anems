# AI Provider Setup

SiteForge AI يستخدم BYOK فقط. افتح Settings واختر OpenAI أو Gemini أو Claude أو OpenRouter، ثم أدخل اسم النموذج والمفتاح. الاتصال يتم مباشرة من جهاز المستخدم إلى المزود عبر HTTPS.

لا تحفظ المفاتيح في README أو ملفات المشروع أو ZIP. تُحفظ محليًا داخل مخزن مشفّر تحت `%APPDATA%\SiteForgeAI`. راجع الملفات التي سيحللها الذكاء الاصطناعي قبل إرسال مشروع حساس، ولا تستخدم مفاتيح الإنتاج في بيئة الاختبار.

إذا تركت المفتاح فارغًا، يعمل إنشاء القوالب والتحليل المحلي، بينما عمليات توليد المحتوى والإصلاح المدعومة بالذكاء الاصطناعي تتطلب BYOK صالحًا.
